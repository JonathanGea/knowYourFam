Angular Family Explorer Workspace v1.0

Kontrak aktif untuk halaman pohon pada branch Angular.

ANGULAR

Layout: global header ringkas → navigation rail → Explorer Panel kontekstual (pencarian, cabang, riwayat, pengaturan) → family canvas → Person Inspector responsif.

Navigasi: tampilan awal menunjukkan keluarga terdekat; peta seluruh keluarga adalah tindakan sekunder, bukan tab mode utama. Ketuk kartu membuka Person Identity Card tanpa mengubah kamera. Tindakan “Jelajahi keluarganya” baru mengganti pusat eksplorasi.

Cabang: ekspansi menghormati Stable Anchor. Pergantian keluarga asal mempertahankan cabang yang sudah dibuka. Cabang yang di-pin dilindungi dari peringkasan otomatis. Peringkasan otomatis konservatif hanya dipertimbangkan pada diagram fokus yang sangat besar, dengan opsi Urungkan.

Source: frontend/src/app/features/family-tree/family-tree.page.*, frontend/src/family-explorer-workspace.css, serta frontend/src/app/application/family-tree.store.ts. Spesifikasi dan acceptance criteria ada di docs/FAMILY-EXPLORER-WORKSPACE.md.

Catatan: bagian-bagian MAIN SOURCE di bawah menjelaskan implementasi HTML lama; detail mode Focus/Overview dan sidebar permanen tidak lagi menjadi kontrak UI Angular terbaru.
